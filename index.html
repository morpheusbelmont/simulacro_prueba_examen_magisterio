Configuración del tiempo

Elige cómo quieres realizar el simulacro. En ambas modalidades registraremos cuánto tardas en cada respuesta.

Este simulacro está diseñado para aproximarse a una prueba de alta exigencia para el concurso docente. No busca premiar la memorización aislada: varias preguntas exigen distinguir competencias, responsabilidades institucionales, principios normativos y decisiones pedagógicas.

  • Tiempo con temporizador: 3 minutos para preguntas normales; 5 minutos para relacionar y arrastrar y soltar.
  • Tiempo opcional: puedes elegir la modalidad sin límite. En ambos casos se registra el tiempo empleado por respuesta y el total.
  • Tiempo por pregunta: 2 minutos para selección única/múltiple; 3 minutos para unir conceptos y arrastrar y relacionar.
  • No podrás avanzar ni retroceder voluntariamente sin responder.
  • Si se agota el minuto, la pregunta se registra como incorrecta y el sistema continúa.
  • Las pistas orientan el análisis, pero no revelan la respuesta.
  • Los errores quedarán registrados para el informe final.
  • Hay selección única, selección múltiple, relación y arrastre/ordenamiento.

Consejo: identifica primero la norma, el sujeto responsable y la finalidad de la actuación. Después elimina las opciones que confundan conceptos próximos.
